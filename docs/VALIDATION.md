# 独立项目验收

日期：2026-10-13（Asia/Shanghai）。此记录区分本地验证、浏览器验证与 GitHub CI；本地通过不代表云端已通过。

## 自动化

- `npm ci`：无第三方 npm 依赖，锁文件可独立安装。
- `npm run verify`：27 个 JS 模块语法检查、64 项测试、显式清单静态构建通过；Node 24 与 Node 26 分别实跑通过。
- 60 项原地图回归测试覆盖十二地点、GLB 几何、地理压缩、相机、导览、倒影和状态。
- 3 项独立交付测试覆盖依赖闭合、构建字节与哈希、真实 HTTP 请求；含目录穿越、额外文件、符号链接、错误方法等边界。
- 1 项发布回归测试直接构建，并核对原创、Three.js 与 Noto 许可文件随静态交付保留。该测试先因遗漏 LICENSE 失败，加入发布清单后通过。
- Three.js 五个 JS 文件与官方 0.180.0 发行包比对一致，其中三个仅增加既有 lint 注释首行，另两个完全未修改。
- 字体替换前后，19,438 个非文字 Blender 网格对象的几何、变换、材质引用一致。GLB 导出后的 714 个非文字分组几何与变换逐项一致；材质数值在 1e-6 精度一致（重新打开 Blender 引起浮点序列化差异）。
- 新 GLB 为 18,266,276 bytes、726 个网格、486,154 个三角形，无 images、textures 或外部 buffer。

## 浏览器

原独立整理版本在 Chromium 中验证了 1440×900、390×844、320×568 和 844×390：地点选择、北海三处取景与返回、自由视角、季节/灯光/暂停、鼠标拖动、Home 全景和加载失败重试；没有页面横向溢出。

公开版本替换模型后，另对 `dist/` 的真实 HTTP 页面回归：桌面全景、环球/崇礼招牌、手机地点选择、北海取景与返回。正常加载无页面横向溢出、无外部资源请求，控制台 0 error / 0 warning。模拟 GLB 请求失败时，新预览图已加载（宽 1380px）、回退状态与重新载入按钮可见；解除阻断后点击恢复实时渲染。故障模拟产生的 1 error / 1 warning 是预期请求失败，不计入正常加载状态。`preview.png` 重新截取自公开版本实时画布，避免继续分发旧字体画面。

## 仍未验证

- 实体手机双指手势、帧率、内存与发热；Safari/Firefox、旧浏览器、原生小工具容器。
- 公网服务安全与生产性能；附带服务器仅监听 127.0.0.1。
- 地理测绘精度：地图本身为艺术化压缩构图。
- 独立仓库包含运行模型，不含完整 Blender 重建工程。

## 复现

```bash
npm ci
npm run verify
npm start -- --dist --port 3037
```

打开终端中的本机 HTTP 地址，不使用 file://。云端结果见仓库 Actions 的 **Verify standalone map** 工作流。
